# 护理助手 APP 上传指南

## 第一步：创建 GitHub 仓库

1. 打开 https://github.com
2. 点击右上角 **"+"** 按钮
3. 选择 **"New repository"**（新建仓库）
4. 填写：
   - **Repository name**: `NursingCareApp`
   - **Description**: `护理助手APP - 家庭护理管理工具`
   - 选择 **Public**（公开）
5. 点击 **"Create repository"**

## 第二步：上传代码

### 方法A：使用网页上传（推荐新手）

1. 在您刚创建的仓库页面
2. 点击 **"uploading an existing file"**（上传已有文件）
3. 把 `NursingCareApp` 文件夹里的**所有文件**拖进去
4. 点击 **"Commit changes"**

> **注意**：要上传整个 NursingCareApp 文件夹里面的内容，不是文件夹本身

### 方法B：使用 Git 命令行

在您电脑的命令行中执行：

```bash
# 1. 进入项目文件夹
cd NursingCareApp

# 2. 初始化 Git（如果提示 already exists 就跳过）
git init

# 3. 添加所有文件
git add .

# 4. 提交
git commit -m "Initial commit - 护理助手APP"

# 4. 连接您的 GitHub 仓库（把 YOUR_USERNAME 换成您的用户名）
git remote add origin https://github.com/YOUR_USERNAME/NursingCareApp.git

# 5. 推送上去
git push -u origin main
```

## 第三步：等待自动构建

1. 上传完成后，点击 **"Actions"** 标签页
2. 您会看到构建任务开始运行
3. 等待 **2-5分钟**（构建需要时间）
4. 看到绿色的 ✅ 表示构建成功

## 第四步：下载 APK

1. 点击构建任务
2. 点击右侧 **"app-debug"**
3. 点击 **app-debug.apk** 下载

## 以后更新代码

每次我帮您修改代码后，您只需要：

1. 下载修改后的文件
2. 在 GitHub 仓库页面点击 **"Add file"** → **"Upload files"**
3. 上传新文件
4. 等待自动构建完成
5. 下载新的 APK

## 常见问题

**Q: 上传文件太大了？**
A: APK 文件不需要上传，那是自动生成的。只需要上传源代码文件夹里的文件。

**Q: GitHub Actions 是免费的吗？**
A: 是的！每月2000分钟构建时间，个人项目完全够用。

**Q: 忘记了用户名怎么办？**
A: 登录 GitHub 后，右上角头像旁边就是您的用户名。
